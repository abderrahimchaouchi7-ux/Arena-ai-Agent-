# مِعْراب — محلّل نحوي عربي محلي

**مِعْراب** تطبيق سطح مكتب عربي يحلّل الجمل كلمةً كلمة ويعرض النوع، والموقع الإعرابي، والحالة، والعلامة، وسبب الترجيح. يعمل المحرّك والواجهة **دون إنترنت**، ولا يُرسل النص خارج الجهاز.

![شعار مِعْراب](assets/icon.png)

## ما الذي بُني؟

- ثلاثة نماذج قواعدية مصغّرة ومتدرجة:
  - **الأساس (سهل):** الجملة الاسمية والفعلية، الفاعل، المفعول به، والجار والمجرور.
  - **التراكيب (متوسط):** النواسخ، النعت، العطف، الإضافة، ونواصب المضارع وجوازمه.
  - **التراكيب المتقدمة (صعب):** الشرط، الاستثناء، النداء، الموصولات، وعلامات الإعراب الفرعية.
- اختيار تلقائي للنموذج وفق طول الجملة ومؤشرات تركيبها.
- معجم عربي صغير + تحليل صرفي خفيف + قواعد سياقية حتمية؛ لذلك يبدأ بسرعة ولا يحتاج GPU أو تنزيل نموذج.
- واجهة RTL عربية ملائمة للحاسوب، مع سجل محلي ونسخ النتيجة وتصدير JSON.
- نافذة سطح مكتب عبر `pywebview` وخادم محلي على `127.0.0.1` فقط.
- وصفة PyInstaller وGitHub Actions لإنتاج `Mi3rab.exe` مستقل لنظام Windows x64.

> **تنبيه علمي:** الإعراب العربي غير المشكول قد يحتمل وجوهًا صحيحة متعددة. مِعْراب يرجّح الوجه الأكثر شيوعًا ويعرض درجة ثقة وتنبيهًا عند الغموض؛ وهو أداة تعليمية سريعة وليس بديلًا عن مراجعة المتخصص للنصوص الأدبية أو القرآنية الدقيقة.

## التشغيل من المصدر

يتطلب Python 3.10 أو أحدث.

```bash
python -m pip install -r requirements.txt
python main.py
```

لتشغيل واجهة الويب فقط أثناء التطوير:

```bash
python main.py --serve --host 0.0.0.0 --port 8765
```

ثم افتح `http://localhost:8765`.

## إنشاء ملف EXE على Windows

من PowerShell داخل المشروع:

```powershell
./scripts/build_windows.ps1
```

سينتج الملف:

```text
dist/Mi3rab.exe
```

الملف التنفيذي أحادي (`one-file`) ويضم بايثون، النماذج، والواجهة. لا يحتاج المستخدم إلى تثبيت Python. يعتمد عرض النافذة على **Microsoft Edge WebView2 Runtime** الموجود افتراضيًا في Windows 10/11 الحديث. جميع عمليات الإعراب تتم محليًا حتى مع وجود WebView2.

يوجد أيضًا مسار CI في `.github/workflows/build-windows.yml` يبني التطبيق على Windows، يشغّل الاختبارات، ثم يرفع `Mi3rab.exe` وملف بصمة SHA-256 كحزمة باسم **Mi3rab-Windows-x64**.

## الاختبارات

```bash
python -m unittest discover -s tests -v
```

تغطي الاختبارات التقطيع، التطبيع، الجمل الاسمية والفعلية، إنّ وكان، النصب والجزم، الشرط، الاستثناء، الإضافة، النعت، العلامات الفرعية، وواجهة API المحلية.

## واجهة API المحلية

### تحليل جملة

```http
POST /api/parse
Content-Type: application/json

{"text":"إنَّ العلمَ نورٌ","level":"auto"}
```

قيم `level`: ‏`auto` أو `easy` أو `medium` أو `hard`.

### مسارات أخرى

- `GET /api/health` — حالة المحرّك.
- `GET /api/models` — تعريف النماذج وقواعد كل نموذج.
- `GET /api/examples` — أمثلة جاهزة.

## بنية المشروع

```text
arabic_parser/
  engine.py       # التصنيف والقواعد السياقية وعلامات الإعراب
  lexicon.py      # المعجم المحلي عالي التواتر
  text.py         # التطبيع والتقطيع
  server.py       # API وخادم الملفات المحلي
models/           # بيانات النماذج الثلاثة وقوائم قدراتها
web/              # واجهة عربية HTML/CSS/JS بلا موارد خارجية
main.py           # تشغيل نافذة سطح المكتب أو خادم التطوير
Mi3rab.spec        # وصفة EXE
```

## الخصوصية والأمان

- لا توجد استدعاءات لخدمات ذكاء اصطناعي أو خطوط أو مكتبات JavaScript خارجية.
- التطبيق المكتبي يستمع إلى `127.0.0.1` على منفذ عشوائي، لا إلى الشبكة العامة.
- سجل الجمل محفوظ في `localStorage` داخل الجهاز ويمكن مسحه من الواجهة.
- الطلب محدود الحجم، والمخرجات المعروضة تُهَرَّب لمنع حقن HTML.
